# holdBTC

BTC 120일 이동평균선 기반 추세추종 자동매매 봇의 상태를 보여주는 계기판.

## 구성
- `index.html` — 현재가 vs 120일선 이격도 게이지, 매수기준선(+2%), 평가손익/최근 매도 수익률, 보유 상태(보유중/현금), 누적 매매 횟수를 표시
- `btc120ma_status.json` — 봇이 매일 실행될 때마다 갱신해서 올리는 상태 데이터

## 전략
- **매수**: 현재가가 120일 이동평균선 대비 +2% 이상일 때 (하락 후 추세 복귀 확인)
- **매도**: 현재가가 5·20·60·120일선 위에서 정배열일 때
- 백엔드 봇이 매일 09:15에 실행되어 상태를 계산 → JSON으로 커밋 → 페이지는 5분마다 다시 읽어옴 (실시간 시세가 아니라 "최근 봇 실행 시점" 기준)
